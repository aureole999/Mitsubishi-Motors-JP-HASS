# Mitsubishi Motors Japan for Home Assistant

日本版の新しい **Mitsubishi Motors** アプリが使用するクラウド API 向けの、非公式 Home Assistant カスタムインテグレーションです。

> [中文说明](README_CN.md)

## 現在の機能

- 日本向け IDM ログインとローテーション型リフレッシュトークン
- 複数車両の検出
- 駆動用バッテリー、充電状態、充電プラグ、充電残り時間
- 空調状態と設定温度
- リモート空調の開始・停止

空調開始は、実車で確認済みの **25 °C** のみを送信します。温度変更、ドアロック、ライト、ホーン、充電操作は日本車で未検証のため実装していません。

## 安全設計

- 定期ポーリングはクラウドのキャッシュだけを読み、車両を起動しません。
- 空調開始時だけ、公式アプリで観測した `refreshVSR` と `wakeUpVehicle` の順序を使用します。
- 開始・停止コマンドは自動再送しません。通信が切れて結果が不明な場合は公式アプリで状態を確認してください。
- 開始・停止を押すと HA は要求したモードをすぐ表示します。失敗時は直ちに戻し、成功時はクラウド状態の確認を待ちます。一時表示は最大2分です。
- アクセストークンは有効期限の5分前に更新し、ローテーションされた最新のリフレッシュトークンを Home Assistant の設定エントリへ保存します。
- パスワード、トークン、VIN、暗号化前後の本文をログへ出力しません。

## インストール

### HACS カスタムリポジトリ

1. このリポジトリを GitHub に公開します。
2. HACS → Integrations → Custom repositories で URL と `Integration` を追加します。
3. **Mitsubishi Motors Japan** をダウンロードして Home Assistant を再起動します。
4. 設定 → デバイスとサービス → インテグレーションを追加 → **Mitsubishi Motors Japan**。

### 手動

`custom_components/mitsubishi_motors_jp` を Home Assistant の `config/custom_components/` へコピーして再起動します。

ログインには日本版の新しい Mitsubishi Motors アプリと同じメールアドレス・パスワードを使用します。旧 Owner Portal の4桁PINは不要です。ログイン失敗はサーバー側で回数制限されるため、誤ったパスワードを繰り返さないでください。

インストール前の読み取り専用接続確認も利用できます。ログインとキャッシュ取得だけを行い、車両の起動や制御コマンドは送信しません。

```bash
python3 tools/check_connection.py
```

## API リクエスト数と速度

初回セットアップでは IDM 初期化・ログイン、Kintaro 初期化、車両一覧と状態取得を行います。通常の更新は車両ごとに2件のキャッシュ読み取りです。

空調開始には車両の起動とリクエスト結果のポーリングが必要です。車載通信モジュールの起動を待つため十数秒から1分程度かかることがあります。VSR の完了を確認してから開始処理へ進み、サーバーの起動期限内に車両が応答しない場合は START を送信しません。開始コマンド自身の結果は個別に確認します。
